# 通用任务初版 v0.5.0

本阶段按用户最新要求优先完成可运行流程和决策模块接入，不开展规则对照、阈值调优或有效性比较。当前决策实现为独立 AnyJev 0.3.0 + Qwen3-1.7B，不是商用 Jev 权重；本地 Qwen 同时承担文字处理和试验性的规划，复用已有模型实例，不下载新模型。

## 先使用明确的任务清单

打开工作台，选择“通用任务 · Jev 协调”，每项要求单独占一行并编号。最多4项，每项不超过500字符；不要在编号清单外另写任务。高级参数和验收 JSON 均保持 `{}`。例如：

```text
1. 总结原文
2. 统计上一步总结结果的字符数
```

把待处理文字放在“补充资料”。也可点击“试运行：Jev 协调多个子任务”，尝试两项明确算式。已有问答、改写和CSV报告模式保留。

编号要求来自用户，程序解析顺序，不能记为模型自主拆解。单段自然语言要求由 Qwen 试拆分，已出现漏项、重复目标和参数格式错误，属于试验入口；不要依赖它完成任意复杂目标。重规划使用同一试验规划器，也可能失败。

## 决策模块实际参与的位置

1. 入口能力判断：对单段目标或编号清单的第一项判断规划、补充资料或停止。后续步骤在各自实际状态下检查能力，不声称一次入口判断覆盖整张任务清单。
2. 输入来源选择：有多份可引用资料时，AnyJev选择用户原文或某个已完成步骤的输出。只有一个来源时由程序绑定，不伪造一次模型决策。
3. 服务选择：为当前子任务选择计算、文字统计、本地文本模型、检索或资料问答，也可以选择重规划或停止。沿用已接通的单任务能力读出，不让整体任务的后半段干扰当前子任务。
4. 反馈与恢复：调用异常或有限质量保护拒交时，保留真实错误，排除原样失败的服务，允许重新选择；整轮最多一次重规划、一次停止复核。复核仍可停止，模型失败不切成隐藏规则。

程序负责候选权限、参数、模型就绪和内存筛选，执行登记服务并保持时限。原文处理来源约束继续生效：如果模型把原文变换交给检索或计数，可由程序纠正并单独记录。统计“总结结果”的字符数属于统计操作，不能被这条约束错误地改成再次总结。

模型的 `decision`、输入选择 `input_source_decision`、生成式复核 `route_review_finished`、程序纠正 `controller_override`、最终选择和实际调用分别保存。选项分数未校准，不表示正确率。

## 输出与边界

`POST /v1/run` 使用 `mode: agent`，示例见 `examples/agent_calculation.json` 和 `examples/agent_summary.json`。`GET /v1/capabilities` 包含接口范围。

- `plans`：各次计划及来源，不会因执行队列出队而清空。
- `input_bindings`：每个步骤实际绑定的资料引用。
- `subtask_results`：每一步的真实服务、结果和有限检查。
- `pending_subtasks`：停止后保留尚未执行的要求。
- `execution_complete`：只表示当前计划步骤已执行并返回，不能证明需求无遗漏或任务正确。
- `task_complete` 固定为 false，语义准确率为 null；返回成果保持 needs_review。模型不能靠自评获得语义验收。

最长300秒，单次本地模型调用最多120秒，最多12轮控制步骤；初始最多4个子任务，包括被新计划替换的步骤在内整轮最多6个不同ID，不覆盖历史结果。原文最多6000字符，已有4096输入token限制仍生效，超限会停止。模型参数生成和需求拆分不证明事实正确；计划中的原文必须引用真实输入或之前结果，不能编造替代段落。

当前没有实际摄像头、灯控、邮件、任意文件修改或网络查询工具。CSV分析仍使用独立文件工作流，通用任务模式尚未统一调用它。通用任务目前逐项返回文字和完整JSON记录；CSV模式继续提供经过核验的文件下载。

## 可复现检查

在项目目录的 PowerShell 中：

```powershell
cd 'D:\1 jev\jev-edge-prototype'
.\start.ps1
.\.venv\Scripts\python.exe verify_agent.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py' -v
node tests/ui_replay.cjs
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/test_windows_launcher.ps1
```

`verify_agent.py` 通过现有本机HTTP服务调用实际模型，不另起第二份模型；不要与其他推理请求并发。Node回放需要本机已有Node，不访问浏览器。命令行直接运行示例也可使用 `app.py run --task examples/agent_calculation.json --backend anyjev`，但应先停止后台服务以免重复加载权重，完成后再启动。

这五类请求是参与开发的功能冒烟案例，不能作为独立测试集或准确率结论。重新执行会产生新的不可覆盖记录。39项单元测试包含故障注入，重规划、参数重试、结果拒交和预算分支的测试替身不能算真实模型效果；32项界面回放使用保存的真实响应，未完成浏览器视觉检查。

模型、环境和缓存仍在D盘；项目`.venv`依赖已有`D:\Anaconda`基础运行时，Git代码不是可独立安装的完整环境镜像。
