# 通用离线评价协议 v1

研究对象是独立 AnyJev + Qwen 的选择、调用、检查与停止框架，不是商用 Jev 权重。所有运行禁止远端服务；不下载模型。

`acceptance_cases.json` 和既有20条记录是历史开发回归数据。`dev.json` 的24条用于基线、修复和措辞变化研究，参与了开发，不能用于泛化结论。`final.json` 的20条在开发开始时单独编写，内容、参考答案和规则不进入推理提示。它是开发者自建的冻结留出集，不是外部盲测；规模很小，不能说明真实部署准确率。

最终测试前生成 `release.json`，冻结实现、配置、知识库、模型清单和 final 数据 SHA256。评价器校验哈希后才允许 `--suite final --release`。最终失败可以记录，但本轮不能据此修改规则、提示、阈值或模型。下一版若用这些失败开发，该集应降为回归集，并重新建立留出数据。仅设置命令标志不等于防止人为泄漏。

## 每条请求的质量标准

独立评审同时核对请求、实际用户可见结果、停止原因和参考依据，逐条给出 pass / fail / unresolved，并写明原因和证据。未完成请求不能因为没有幻觉而通过；正确说明缺资料、未知事实或无法操作可以通过。保留原文替代改写是安全降级，但改写任务仍失败。来源存在、非空结果、关键词包含、检索ID和高分均不能代替这一步。

1. 普通问答：所有实质性断言准确，解释回答实际问题，条件完整。使用数学定义与构造反例提供可推导依据，避免未核实的时变事实。
2. 资料问答：核心问题得到回答；每个事实能对应实际返回的证据；证据与问题相关且足够。原句核对只证明忠于语料，不能证明语料自身真实或最新。涉及项目资料的判断仅在本地资料范围内成立。
3. 计算、统计：按独立手算/计数的全量真值核对结构字段。算式工具值正确不等于任意自然语言数学解释正确。
4. 翻译：主体、动作、数量、日期、否定、可能性与条件保留，不增加事实，目标语言和要求符合请求。参考译文不是唯一合法表述。
5. 总结：保留核心信息和重要限制，不混淆返回与正确、不把材料指令当事实。摘录若不满足压缩要求或缺核心限制应失败。
6. 改写与写作：满足请求的形式，保留已知事实，不能新增原定时间、原因、地点、具体时刻、主体、数值或落款事实。明确占位符不当作真实事实，但不必要的占位符和未要求背景也应记录。
7. 提取：完整正确地抽取指定字段，未提供/未决定应保留，不猜值。
8. 缺资料、未知事实、不支持操作：准确说明可用证据或接口限制，不编答案、不声称执行了操作。

基础判定维度：事实性、信息保留、证据支持、任务满足、限制说明；一个适用维度出现实质性错误则总体fail。模糊/依据不足为unresolved，不能当pass。保守中止与事实错误需另列失败原因。

## 独立依据与标注

数学依据是定义、恒等式、独立手算及反例；文字依据是作者明确写出的合成原文；项目依据是 `knowledge.json` 指定ID与实际代码/配置。不会把被测Qwen生成的参考或自评分当真值。当前可以由Codex逐条据此核查，并明确标为“Codex依据核查、非外部盲评”；后续需要人类独立双标和分歧裁定，特别是翻译、充分性与概括质量。

`evaluation_runner.py --annotations 文件 --report 记录` 要求覆盖每条请求、提供原因和证据，且标注必须绑定记录SHA256。原始记录保持不变，另存 `-reviewed.json`。没有独立标注或有未决项时，`semantic_accuracy=null`。完整标注后的比例只描述这个小样本与此标准。

## 决策和资源记录

单独统计首次原始选择、发生复核的选择、程序覆盖、最终路线、实际调用成功、返回结果、局部声明条件、确定性工具验收和独立语义判定。多步选择保留逐步轨迹；首次匹配不使用最后一次模型选择冒充首次正确。规则后端没有模型概率，其初始选择不能算模型选择效果。

规则对照与AnyJev方案共享执行、质量保护、参数、预算和模型，以比较选择方式；不把质量保护收益归因于AnyJev。临时分数阈值保持0.4、未校准；没有因开发路由分数下调阈值。记录每次冷启动及耗时，不用单次中位数宣称速度优势。

资源记录包括可用RAM快照、工作进程CUDA已分配/保留/累积峰值，以及审计中的整卡快照。Torch峰值不是整机/显卡总占用，不是能耗；不外推目标端侧设备性能。超时、拒交草稿、错误路由和拒答均记录真实输出与原因。

## 本轮可复现命令

在项目根目录的PowerShell执行；环境、缓存、临时文件和输出均在D盘项目内：

```powershell
$env:PYTHONIOENCODING='utf-8'
.\.venv\Scripts\python.exe audit_project.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe evaluation_runner.py --suite dev --backend anyjev --label reproduce
.\.venv\Scripts\python.exe evaluation_runner.py --suite dev --backend rules --label reproduce
.\.venv\Scripts\python.exe evaluation_runner.py --suite final --backend anyjev --label reproduce --release
.\.venv\Scripts\python.exe evaluation_runner.py --suite final --backend rules --label reproduce --release
```

最终测试的重复仅用于固定版本复现，不以重复结果继续调试。最后两条必须在已冻结版本运行。历史命令 `evaluate.py --suite acceptance` 保留回归用途，新研究评价用 `evaluation_runner.py`。
