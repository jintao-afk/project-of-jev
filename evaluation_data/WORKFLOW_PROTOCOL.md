# v0.4.0 文件任务评价

研究对象为独立AnyJev + Qwen的端侧选择与调用框架，非商用Jev。保持离线与原权重。

## 范围

结构化任务声明：workspace/inbox中的1至2份UTF-8 CSV、数值字段、可选状态字段、可选严格大于阈值、可选模型检查建议。最多16步、300秒，单次本地模型调用120秒；CSV每份最多1MB/5000行/32列，目录最多32个直接条目，参考文字最多两份、每份16KB。程序绑定参数和可执行依赖，模型从已筛选动作中选择。不是任意自然语言任务的自动规划器。

完成条件：所需统计、阈值和比较已完成，报告已写出并重读核对，交付前再次检查源文件与成果。数值保留六位小数；缺失及非法数值不计入数值统计，并披露行号。状态仅按原值计数。两份表按files声明顺序、未声明时文件名排序，差值为第二份减第一份。缺少有效数值、必需字段或材料不能交付。

行号按CSV逻辑记录编号且包含表头；含引号换行的CSV字段不对应逐条物理文本行号。

可选模型建议始终为未验证检查事项，不属于已确认原因；包含建议时状态needs_review，即使声明的结构化文件任务已完成。task_complete与completion_scope须一起解释，不能据此宣布自然语言语义全部正确。

## 决策与机制记录

原始AnyJev选择、生成式停止复核、实际执行及验收分开；规则对照共享工具、依赖、权限、预算与验收。每请求最多一次停止复核，复核仍可停止；原始低集中度只保留为未校准观察值，本文件任务没有用单次问答的0.4临时阈值拦截可执行动作。既有单次处理阈值未改；这是单独声明的工作流策略，不是阈值调低后宣称成功。

程序只提供有限候选与依赖。只有一个非停止可用动作的阶段必须单列，不能把这些选择当成模型复杂规划效果。比较完成率、证据覆盖、额外调用、错误停止和耗时；不以动作选择次数证明价值。

报告损坏时最多允许一次重写并重新验证；源文件已改变时停止，不能用旧统计继续交付。单元故障注入使用测试替身，与真实模型补救分开。成果只有产生delivery.json且字节哈希匹配才可下载；请求下载已变更成果返回冲突。

## 数据与参考

workflow-dev.json的4项任务用于开发。demo来自既有真实运行记录，比较内容只是数据处理演示，不是新的模型优劣证据。workflow-final.json另行编写4项小型留出，含正常分析、两表比较、缺字段、缺材料；freeze_workflow.py在运行前写一次release-v040.json。冻结后不按留出修改代码或提示，后续使用其失败必须降级回归并重新划分。

evaluate_workflow.py独立用Fraction有理数算法检查数值、完整计数、缺失/非法行、阈值命中明细、比较和源文件哈希，与生产Decimal统计分离。停止案例要求实际失败证据，提前泛化停止不能仅因最终没有答案就通过。程序内部重算不是独立真值；外部Fraction核对也只覆盖已声明数学与来源条件，不是完整语义判断。原始semantic_accuracy仍null。模型建议另需独立人工/依据核查，不能用Qwen自评。

这是开发者自建、规模很小的留出，非外部盲测。Torch资源为进程分配峰值，不是整卡显存或能耗；顺序冷热运行耗时不构成受控效率优势证明。
