## 初版的明确选择

| 模块 | 当前实现 |
|---|---|
| 本地决策 | AnyJev 0.3.0 + Qwen3-1.7B；完整选项旋转读出，prior=content_free |
| 本地文本处理 | 复用上述 Qwen 模型实例，关闭生成阶段的 thinking，减少重复模型占用 |
| 专用模型 | BAAI/bge-small-zh-v1.5，本地资料检索，先在 CPU 上运行 |
| 程序工具 | 受限四则运算、文本统计、受限CSV分析及核验报告 |
| 远端兜底 | DeepSeek 兼容接口；默认禁止远端请求，密钥从环境变量读取 |
| 商用 Jev 对照 | TypeSafe Choice HTTP API；单独标记后端与模型版本 |
| 框架接口 | 本机 HTTP `/v1/run` 支持single、workflow与agent模式，`/v1/capabilities`列出范围；`/v1/artifacts/<任务ID>/report.md或json`下载已核验成果；`/v1/tasks`保存与读取任务，`/v1/tasks/<任务ID>/continue`补充后继续；Harness原生插件尚未实现 |

本地开放实现与商用 Jev 是不同模型。界面中“Jev 决策模块”是方案模块名称，日志始终记录实际后端。固定规则是独立对照，模型失败时不偷偷切成规则并冒充模型推理。

## 准备与启动

现有模型与环境已安装。在此目录运行，或双击 `打开工作台.cmd`：

```powershell
./start.ps1
```

页面地址：<http://127.0.0.1:8765>。当前运行完全离线，使用项目内既有权重；无需重新安装或下载模型。历史安装脚本保留供明确需要重建环境时使用。

启动脚本在后台运行本项目服务，再次启动不会重复创建已登记服务。使用 `./stop.ps1` 停止；脚本检查进程 ID 与启动时间匹配后才停止本项目进程。

本机 Hugging Face 域名解析失败时，使用对应魔搭仓库：`./setup.ps1 -DownloadModels -ModelSource modelscope`。魔搭路径记录每个文件的 revision 与 SHA256，按文件校验；两种平台的仓库版本标识不能混用或声称天然一致。

需要远端兜底时，在本机环境配置 `DEEPSEEK_API_KEY`；需要商用 Jev 对照时配置 `TYPESAFE_API_KEY`。不要把密钥发送到聊天或写入项目。配置后重新启动服务，并在页面明确允许该次处理使用远端服务。

命令入口也可使用显式任务文件：

```powershell
./.venv/Scripts/python.exe app.py run --task examples/calculation.json --backend anyjev
```

`--backend rules` 是固定规则对照，`--backend jev_api --allow-remote` 是商用 Jev 联网对照。没有模型文件或凭据时，会明确返回未准备/停止，不显示假推理结果。

## 共性机制

1. **筛选：**依据模型文件准备状态、内存、网络允许状态、凭据、剩余额度和已失败候选筛选。初版的内存下限仅为保守阻断条件，不保证显存足够；显存不足由调用失败反馈。
2. **选择：**决策输入包含处理要求、资料、能力清单、已有结果和预算。输出必须覆盖本次全部候选，概率须有限、在 0 到 1 内且和为 1。停也是候选。
3. **控制：**按临时分数阈值、执行条件及剩余资源决定执行/升级/停止。程序覆盖模型选择时在日志另记，不能当作模型原始选择。
4. **参数：**初版采用显式参数及固定映射；计算需要 `parameters.expression`。尚未实现任意自然语言到任意工具参数的自动生成。
5. **执行：**调用登记的服务，不执行模型产生的任意代码、文件操作或工具计划。大模型目前只返回文本，自动执行大模型重规划尚未实现。
6. **验收：**调用成功单独记录。没有验收条件时返回 `needs_review`。字符串、检索ID条件通过仅记局部条件通过，仍是待检查；只有声明真值核对通过的确定性计算或全量统计结果才记 `task_complete=true`。独立语义标注另存，不能用同一小模型自评代替。
7. **反馈：**失败/验收不合格反馈给决策模块，下一步排除已失败候选，避免原样重复；初版每个候选最多尝试一次，尚未实现参数修复后重试同一候选。
8. **界限：**最多 3 个步骤、300 秒总时间、单次调用最多 120 秒、最多 512 生成token、4096 输入token。当前完全离线，远端请求为0；接口仅保留作未来兜底。推理独立进程超时终止。

`network_available` 是调用方提供的网络状态声明；并非已经成功连接的证据。实际连接失败仍会捕获并反馈。日志存本地 `logs/`，会包含输入与输出；进入真实领域数据前需要确定保存策略。

## 升级与成本

初版统一从选项概率计算 Choice 集中度：`(p_max - 1/n) / (1 - 1/n)`。它不是正确率，也不是单独训练出的“成功概率”。暂用 0.4 作流程参数，配置明确 `threshold_calibrated=false`。AnyJev 的选项旋转读出不替代面向任务真值的概率校准。

低于临时阈值时，允许且可用才请求大模型；否则停止。调用次数预算包括商用 Jev 决策请求和兜底请求，也包括失败请求。当前未实现金额预算：只记录 token 使用量与调用次数，费用设为 null，不假造节约比例。
